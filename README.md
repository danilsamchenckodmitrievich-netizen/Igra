# DotA 3

Браузерная MOBA в духе Dota: Свет против Тьмы, 5 на 5, три линии, лес с нейтралами,
башни и Древний, которого нужно разрушить. Вы управляете одним героем, остальные девять —
боты.

## Как запустить

Откройте `index.html` в браузере. Сборка и сервер не нужны.

Если браузер блокирует локальные файлы, поднимите любой статический сервер из корня
репозитория, например:

```bash
npx serve .
# или
python3 -m http.server 8000
```

## Что есть в игре

- Карта 6000×6000: три линии, река, лес с проходами, базы с фонтанами и Древними.
- 6 героев, у каждого 4 способности (три обычные и ультимейт), 25 уровней.
- Волны крипов каждые 30 секунд; крипы усиливаются со временем, после падения
  башни 3 уровня на линии выходят суперкрипы.
- 11 башен у каждой стороны. Башни, Древний и следующая башня на линии неуязвимы,
  пока не разрушена предыдущая.
- 8 лагерей нейтралов (кобольды, волки, огр с шаманом) с возрождением каждую минуту.
- Древний Голем в логове на реке. За победу над ним команда получает золото, а герой —
  Эгиду бессмертия: одно воскрешение на месте гибели в течение 5 минут.
- Лавка на 18 предметов: зелья, свиток телепорта, сапоги, кинжал рывка, щит
  бессмертия, артефакты. Вне базы покупки доставляет курьер.
- Туман войны, миникарта, таблица счёта, серии убийств, первая кровь.
- Боты: добивают крипов, отступают на низком здоровье, используют способности и
  предметы, телепортируются на линию, после 15-й минуты собираются для пуша.
- Три уровня сложности вражеских ботов.
- Работает на телефоне: касание — приказ, жест пальцем — обзор, щипок — масштаб.

## Управление

| Клавиша | Действие |
| --- | --- |
| ПКМ / ЛКМ | Идти или атаковать цель |
| Q W E R | Способности (повторное нажатие на способности для союзника — применить на себя) |
| Shift + Q…R, кнопка «+» | Изучить способность |
| 1–6 | Предметы |
| A | Атака с движением |
| S | Стоп |
| B | Лавка (двойной клик или ПКМ по предмету — быстрая покупка, ПКМ по слоту на базе — продажа) |
| Tab | Таблица счёта (удерживать) |
| Пробел | Камера к герою |
| Y | Закрепить или освободить камеру |
| Колесо мыши | Масштаб |
| Стрелки, края экрана | Обзор карты |
| Esc, P | Пауза |
| M | Звук |

На миникарте ЛКМ двигает камеру, ПКМ отправляет героя, а при выборе цели свитка
телепорта можно щёлкнуть прямо по миникарте.

## Герои

| Герой | Роль | Способности |
| --- | --- | --- |
| Громовой Клинок | Керри, ближний бой | Рывок молнии, Вихрь, Громовой удар (крит), Буря клинков |
| Пиромант | Маг, дальний бой | Огненный шар, Огненный столп (оглушение), Тлеющее пламя, Метеорит |
| Ледяная Ведьма | Контроль, дальний бой | Ледяная стрела, Ледяной щит, Морозное касание, Вечная зима |
| Каменный Титан | Танк, ближний бой | Удар о землю, Каменная кожа, Шипы, Падение горы |
| Теневой Охотник | Убийца, дальний бой | Ядовитая стрела, Шаг в тень (невидимость), Инстинкт охотника, Метка смерти |
| Жрица Рассвета | Поддержка, дальний бой | Святой свет, Ослепляющая вспышка (безмолвие), Аура благодати, Небесное благословение |

## Устройство кода

Обычные скрипты без сборки, порядок подключения задан в `index.html`.

| Файл | Что внутри |
| --- | --- |
| `js/util.js` | Математика, генератор случайных чисел, шум, куча для A* |
| `js/data.js` | Константы, крипы, башни, нейтралы, босс, герои, предметы |
| `js/map.js` | Линии, река, генерация леса, сетка проходимости, поиск пути A* |
| `js/entities.js` | Юниты и герои, бафы, урон, атаки, применение способностей, инвентарь |
| `js/abilities.js` | 24 способности героев и активные предметы |
| `js/ai.js` | Поведение крипов, башен, нейтралов, босса и ботов-героев |
| `js/game.js` | Матч: волны, лагеря, видимость, смерть, золото и опыт, снаряды и эффекты |
| `js/icons.js` | Процедурные иконки способностей, предметов и героев |
| `js/render.js` | Отрисовка карты, юнитов, эффектов, тумана войны и миникарты |
| `js/audio.js` | Синтезированные звуки через WebAudio |
| `js/ui.js`, `js/input.js`, `js/main.js` | Интерфейс, управление, меню и игровой цикл |
